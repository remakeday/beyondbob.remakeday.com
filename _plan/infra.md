## 구성이 단순해졌습니다

계정 시스템이 없고 클라이언트가 웹 하나이므로, 이전 계획(Docker Compose + Nginx 자체 호스팅 + 앱 배포)은
과잉입니다. **웹은 Vercel, API는 컨테이너 1대**로 충분합니다.

```
                     인터넷 (공개 투표 트래픽)
                            │
        ┌───────────────────┴───────────────────┐
        │                                       │
   Vercel (웹)                            api.… (FastAPI)
   프론트 5장                              │
   프리뷰 배포 자동                    ┌────┴────┐
                                  PostgreSQL   LLM Provider
                                  (+ 벡터)     (비용 상한 필수)

  GitHub Pages ──── beyondbob.remakeday.com   ← 이 개발 허브
                    (가비아 도메인 연결 완료)
```

| 대상 | 어디에 | 상태 |
|---|---|---|
| 개발 허브 (이 사이트) | GitHub Pages + 가비아 도메인 | ✅ 완료 |
| 게임 웹 | **Vercel** | 계정 등록 완료, 프로젝트 연결 대기 |
| API | 컨테이너 1대 | D-12 |
| DB | PostgreSQL + 벡터 인덱스 | D-12 |

## 공개 투표 대응이 인프라 요구사항이다

12.4가 곧 비기능 요구사항입니다.

| 기획서 요구 | 인프라가 해야 할 일 |
|---|---|
| **30초 안에 판단** | 첫 화면 TTFB 최소화. Vercel 엣지 캐싱 |
| **로그인·설치 없이 즉시 진입** | 세션 발급이 첫 요청 안에서 끝나야 함 |
| 첫 루프를 짧게 | 아침 화면은 LLM 호출 없이 즉시 렌더 |
| 트래픽 급증 가능 | **LLM 비용 상한이 곧 가용성 한계** |

<div class="callout callout--danger">
  <div class="callout__title">공개 투표에서 가장 먼저 터지는 건 서버가 아니라 LLM 비용입니다</div>
  <p>익명 진입이므로 <strong>봇·크롤러·반복 접속에 그대로 노출</strong>됩니다.
  세션당·IP당 루프 수 제한과 일일 비용 상한을 <strong>공개 전에</strong> 걸어둡니다.
  상한 도달 시 게임이 멈추므로, 상한을 얼마로 잡을지가 곧 서비스 판단입니다.</p>
</div>

## 시크릿

| 키 | 저장 위치 |
|---|---|
| `DATABASE_URL` | GitHub Secrets + 서버 `.env` + Vercel 환경변수 |
| `LLM_API_KEY` (역할별 분리 가능) | 동일 |
| `LLM_DAILY_LIMIT_USD` | 동일 |
| `SESSION_SIGNING_KEY` | 동일 |

레포에는 **`.env.example` 만** 올립니다. D-3(9/13)에 시크릿 스캔.

## 파이프라인

| 파이프라인 | 트리거 | 하는 일 |
|---|---|---|
| 백엔드 CI | PR | lint + pytest + **import-linter (아키텍처 테스트)** |
| 백엔드 CD | `main` 머지 | 스테이징 반영 |
| 웹 | push | **Vercel 자동 배포 + PR 프리뷰** |
| 개발 허브 | push | Jekyll → Pages (동작 중) |
| 프로덕션 | 태그 + 수동 승인 | 마이그레이션 → 배포 → 헬스체크 |

<div class="callout callout--ok">
  <div class="callout__title">아키텍처 테스트를 머지 게이트로 건다</div>

  AI가 생성한 코드의 드리프트를 사람 눈이 아니라 기계로 막는 장치이고,
  배지를 README에 노출해 심사에서 근거로 씁니다.</p>
</div>
