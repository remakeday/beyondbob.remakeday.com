## 연출 원칙이 디자인 규칙이다

> 전면 텍스트 기반이며, **사망 장면은 직접 묘사하지 않는다.**

- 사건 자체가 아니라 **정황과 단절**로 전달한다
- 하루가 끝나는 방식, 마지막에 남은 말, 되돌아온 아침으로 처리한다
- 공개 배포 환경이므로 폭력·유혈 묘사를 배제한다

이는 표현 제약이 아니라 **설계 선택**입니다. 유저가 무슨 일이 있었는지 추론하는 것이 이 게임의
핵심 행위이므로, 사건을 직접 보여주지 않는 편이 메커니즘과 일치합니다.

**손상 연출도 같은 원칙을 따릅니다.** 손상은 설명되지 않고 발생만 합니다.
시스템은 "무언가 이상하다"고 알려주지 않으며, **이상함을 감지하는 것은 전적으로 유저의 몫**입니다.

## 아침 화면 — 가장 중요한 한 장

```
7시 12분. 눈을 뜬다.        ← 고정. 1루프에도 동일
천장이 조금 낮아 보인다.     ← 손상 1층 작동 지점
```

| 규칙 | 이유 |
|---|---|
| 매 루프 **같은 문장**으로 시작 | 반복이 몸에 익어야 어긋남이 감지된다 |
| **분 단위 숫자**를 노출 | 루프의 정확성을 증명. 1루프에서 무심코 지나친 숫자를 2루프에서 알아본다 |
| **두 번째 문장부터** 미세하게 흔든다 | 안심시킨 직후에 흔드는 순서 |
| 후반에 첫 문장을 **한 번만** 건드린다 | 7시 12분 → 7시 13분. 스무 번 같았기 때문에 1분이 크게 느껴진다 |
| **루프 카운터를 노출하지 않는다** | 유저가 세게 만든다. 노트가 그 역할을 한다 |
| 하루가 끝나는 방식은 매번 다르다 | 같은 결말이 반복되면 긴장이 죽는다 |

<div class="callout callout--danger">
  <div class="callout__title">"7시 12분"은 프론트에서 하드코딩하지 않습니다</div>
  <p>후반에 한 번 바뀝니다. 서버가 <code>morning.fixed</code> 로 내려주는 값을 그대로 렌더합니다.
  프론트가 상수로 박아두면 이 연출이 죽습니다.</p>
</div>

## 대화창

- 남은 **발화 예산**을 항상 보이게. 이게 이 게임의 유일한 자원이다
- 의심도·신뢰도는 **절대 노출하지 않는다.** 인스펙터에서만
- 스트리밍 중 글자가 실시간으로 쌓이고, 툴 호출 중에는 진행 표시 (`event: tool`)
- 자체 타임아웃을 걸어 무한 로딩을 막는다

## 루프 노트 — 대표 캡처

루프가 쌓일수록 촘촘해지는 **타임라인** + 자연어 **검색창**.

- 노트는 정보가 아니라 **감각 파편**의 집합이다 (4.3). 문장이 짧고 불완전한 편이 맞다
- **2층 손상(노트 불일치)이 여기서 발현**된다 — 적어둔 것과 현실이 다르다
- 유저의 유일한 무기를 못 믿게 되는 것이 이 층의 핵심이므로, **UI가 "오류"처럼 보이면 안 된다.**
  불일치는 조용히 존재해야 한다

## 인스펙터

8.8 출력 구조를 그대로 화면으로 옮깁니다.

```
발화: "어제 B가 네 얘기 물어보더라"
내부: 의심 판정   → 의심도 +5 (누적 41 / 임계 60)
      도구 호출   → ask_npc(B, "유저 얘기") [탐문 예산 2 → 1]
      도구 결과   → "없음" · 부작용: B.의심도 +6
      불일치 판정 → 의심도 +15 (누적 56 / 임계 60)
      신뢰 판정   → 변화 없음 (비용 없는 발화)
      재계획      → 트리거: 탐문 결과 불일치 / 계획 수정 없음
출력: "그래? …B가 그런 말을 했다고."
```

> **게임으로는 미스터리, 기술로는 완전한 인과 추적.**

**전이 도메인에서도 같은 화면이 열립니다.** 용어만 어댑터에서 갈립니다
(의심도 → 설득 저항, 신뢰도 → 라포). 10.3 시연의 전부가 이 장면입니다.

## 침묵 권고 배너

```
권고: 침묵
근거: 최근 3턴 의심도 +14, 신뢰 회복 이벤트 없음
                                  [ 따른다 ]  [ 무시한다 ]
```

| 규칙 | 이유 |
|---|---|
| **희소하게** 뜬다 | 매번 뜨면 가드레일이지 판단이 아니다 |
| **근거를 반드시 함께** | 근거 없는 조언은 믿어지지 않는다 |
| 무시가 **자연스러워야** 한다 | 무시를 어렵게 만들면 수용률 데이터가 오염된다 |
| A/B — 근거 표시 유무 | 11.2 마지막 지표. 처음부터 분기 |

<div class="callout callout--danger">

## 토큰

  <div class="callout__title">컨셉 영상이 아직 레포에 없습니다</div>
  <p>색·모션·정보 밀도는 미확정입니다. 다만 <strong>텍스트 전면 · 정황과 단절 · 손상은 조용히 발생</strong>이라는

- **읽기가 전부인 제품**이므로 본문 타이포가 최우선. 한글 행간 **1.8 이상**, 어절 단위 줄바꿈
- 화면이 조용해야 손상 연출이 드러난다 — 장식·애니메이션 최소
- 상태색은 3종만 선확정: `danger #EF6461` · `warn #F2C94C` · `success #31D0AA`
- 간격 4px 배수 / 반경 sm 6 · md 10 · lg 16

## 접근성 최소선

- 본문 대비비 4.5:1 이상
- 터치 영역 44×44
- 주요 플로우를 **키보드만으로** 완주 (대화 입력 → 전송 → 권고 응답)
- 시스템 글자 크기 확대 시 잘림 없음
