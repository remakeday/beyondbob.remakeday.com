## 지금 시점에 확정된 것

기획서를 대조하지 않아도 **바뀌지 않을 것**들입니다. 팀은 이걸 기준으로 오늘부터 달릴 수 있습니다.

1. **9/16 프로덕션 오픈** — 날짜는 고정. 못 맞추면 범위를 줄인다.
2. **백엔드 구조** — 모듈러 모놀리스 · 헥사고날 · 테이블 1개 = Fractal 11-File Set 1벌.
3. **클라이언트 2종** — 웹(김충식) · 앱(이은상). 두 클라이언트는 **같은 API 계약**을 본다.
4. **AI 에이전트는 별도 Bounded Context** — 도메인 백엔드와 포트로만 대화한다.
5. **인증은 모든 화면의 선행조건** — 그래서 D-11(9/05)까지 끝낸다.
