- [ ] **⑤ 전이 시연** — 어댑터 교체로 감사 대응이 돌고, **같은 인스펙터가 열린다**

## 기능 체크리스트

### 게임 루프

- [ ] 첫 진입 시 로그인 없이 **아침 화면**까지 도달 (12.4)
- [ ] "7시 12분. 눈을 뜬다." 고정 문장이 매 루프 동일
- [ ] 두 번째 문장에서 손상 1층 발현
- [ ] 발화 예산이 표시되고 소진 시 발화 차단
- [ ] 하루 5비트 진행 → 죽음 → 아침 복귀
- [ ] 루프마다 발화 예산 감소, **하한 3** 유지
- [ ] 아무 말 없이 루프를 흘리면 예산 회복
- [ ] 루프 카운터가 **화면에 노출되지 않음**

### 판정

- [ ] 의심도 임계 돌파 시 NPC가 유저 말과 **반대로** 행동
- [ ] 신뢰는 발화로 오르지 않고 **비용을 치른 행동**에서만 오름
- [ ] "거짓 출처를 빌린 진실"이 `ask_npc` 로 검증되어 **발각됨**
- [ ] 이름을 빌린 쪽(준)의 의심도가 오르는 **부작용** 확인
- [ ] NPC 탐문 예산 초과 시 호출 거부
- [ ] 민석에게는 빌린 출처가 **통하지 않음**
- [ ] 의심도·신뢰도가 유저 화면에 **노출되지 않음**

### 침묵 권고

- [ ] 임계 근접 시 **희소하게** 발동
- [ ] 근거가 함께 표시됨
- [ ] 수용 / 무시 버튼이 **동등하게** 배치
- [ ] 무시 시 로그에 `ignored` 기록
- [ ] 근거 표시 유무 **A/B 분기** 동작

### 손상 3층

- [ ] 1층 대사 미세 변형
- [ ] 2층 노트 불일치 — **오류처럼 보이지 않음**
- [ ] 3층 충식 소실 — 준에게 물으면 "누구요?"
- [ ] 손상이 **루프를 넘어 누적** (리셋 안 됨)
- [ ] 손상이 루프 수가 아니라 **개입 깊이**에 비례

### 엔딩

- [ ] 반복 / 고립 / 망설임 / 인계 4종 도달 가능
- [ ] Evaluator가 **원인 체인 서술**을 생성

### 전이

- [ ] 어댑터 교체만으로 감사 대응 시나리오 실행
- [ ] **엔진 코드 변경 없음** 확인 (diff로 증빙)
- [ ] 같은 인스펙터가 감사 도메인에서 열림
- [ ] 커리어 시나리오가 같은 링크에서 진입 가능

### 인스펙터 · 데이터

- [ ] 발화 1건의 판정 체인 전체 개봉
- [ ] 도구 호출·부작용이 체인에 표시
- [ ] 11.2 지표가 실제로 집계됨 (세션 수·완주율·루프 분포·엔딩 분포·**권고 수용률**)

### 아키텍처

- [ ] **import-linter CI 통과**, 배지 노출
- [ ] 도메인 계층 유닛테스트가 **LLM 없이** 통과
- [ ] 역할별 스키마 통과율 / 재시도율 계측

### 오류 상황

- [ ] LLM 타임아웃 → 재시도 후 안내
- [ ] 스키마 위반 → 재시도, 게임 상태 안 깨짐
- [ ] 네트워크 끊김 → 안내, 진행 상태 보존
- [ ] 비용 상한 도달 → 정해진 안내

### 배포

- [ ] 프로덕션 마이그레이션 1회 성공
- [ ] `downgrade` → `upgrade` 왕복 검증
- [ ] **롤백 리허설 성공**
- [ ] 시크릿 스캔 0건
- [ ] 세션/IP당 루프 제한 + 일일 비용 상한 동작
- [ ] 온콜 담당·연락 경로 확정
