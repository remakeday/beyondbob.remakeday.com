## 릴리스 체크리스트

오픈 전에 **한 항목씩 사람이 확인하고 이름을 적습니다.** 자동화된 것도 눈으로 봅니다.

### 기능

- [ ] 회원가입 → 로그인 → 로그아웃 (웹 · 앱)
- [ ] 토큰 만료 후 자동 갱신 (웹 · 앱)
- [ ] 프로필 조회 · 수정, 타인 수정 시 403
- [ ] 핵심 리소스 생성 → 목록 → 상세 → 수정 → 삭제
- [ ] 이미지 업로드 후 조회
- [ ] AI 대화 시나리오 3개 완주 (웹 · 앱)
- [ ] AI 스트리밍 중단 · 재시도
- [ ] 목록 페이지네이션 (끝까지 스크롤)
- [ ] 랜딩 페이지
- [ ] 개인정보처리방침 · 이용약관 공개 URL

### 오류 상황

- [ ] 네트워크 끊김 → 안내 표시, 앱이 죽지 않음
- [ ] 서버 500 → 오류 화면 + 재시도
- [ ] AI 프로바이더 장애 → AI 만 비활성, 나머지 정상
- [ ] 잘못된 입력 → 필드별 오류 표시
- [ ] 빈 목록 → 빈 상태 화면 (흰 화면 아님)

### 데이터

- [ ] 프로덕션 마이그레이션 1회 성공 (소요시간 기록)
- [ ] `downgrade` → `upgrade` 왕복 검증
- [ ] 백업 실행 및 **복구 리허설 성공**
- [ ] 시각 표시가 KST 로 맞음

### 보안

- [ ] 레포 시크릿 스캔 0건
- [ ] 타인 리소스 접근·수정 시도 전건 403
- [ ] 프롬프트 인젝션 3건 방어
- [ ] HTTPS 적용, HTTP 접근 시 리다이렉트
- [ ] CORS 화이트리스트 (와일드카드 금지)

### 성능

- [ ] 핵심 API 동시 50 요청 p95 < 1s, 에러율 < 1%
- [ ] AI 첫 토큰까지 시간 목표치 충족
- [ ] 웹 Lighthouse 목표 점수
- [ ] 앱 콜드 스타트 목표치

### 배포

- [ ] RC 빌드 태깅 · 릴리스 노트

- [ ] **롤백 리허설 성공**
