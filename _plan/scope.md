## 우선순위 9단계 (기획서 12.3)

| 순위 | 항목 | 방어선 | 왜 이 자리인가 |
|---|---|---|---|
| **①** | 대화 + 의심/신뢰 판정 + `ask_npc` | ✅ | 한 덩어리. 탐문 도구가 없으면 "거짓 출처를 빌린 진실"이 검증 불가능해져 핵심 기술이 그냥 프롬프트 문장이 된다 |
| **②** | 침묵 권고 + 수용/무시 로깅 | ✅ | **측정 ②가 여기서만 나온다.** 빠지면 2.4가 절반만 성립. 구현 비용은 상태 추정 함수 하나 + 로그 필드 둘 |
| **③** | 루프 + 노트 축적 + 손상 3층 | ✅ | 세계가 닳는 게 안 보이면 반복이 단순 재시도가 되고, 민석의 동기가 일방적 주장으로 남는다 |
| **④** | 민석 예외 계층 + 정체 발현 트리거 | ✅ | 새 시스템이 아니라 **정책 분기.** 같은 NPC 인터페이스에 메모리 정책만 다르게 주입 |
| **⑤** | 전이 시연 (도메인 어댑터 교체) | ✅ | 채용 어필의 핵심 근거. 코어가 완성돼 있으면 실제로는 짧은 작업 |
| ⑥ | 인스펙터 + 아키텍처 CI | | |
| ⑦ | 나머지 데이터 수집 | | |
| ⑧ | 노트 검색 (`search_notes`) | | 데모 범위에선 노트 전량을 컨텍스트에 넣어도 굴러감. **인터페이스만 뚫고 구현은 미룬다** |
| ⑨ | 모델 벤치마크 / 연출 개선 | | |

**다섯이 다 있는 제출물은 이렇게 읽힙니다** — *"믿게 만드는 문제를 시스템으로 다뤘고, 사람의 시도를 데이터로 쌓았고, 두 도메인에서 돌렸다."*

## 자르는 순서

기획서가 정해뒀습니다. 위에서부터가 아니라 **아래에서부터** 자릅니다.

```
1순위 컷  ⑨ 모델 벤치마크 · 연출 개선
2순위 컷  ⑧ search_notes 구현      → 인터페이스만 남기고 전량 컨텍스트로
3순위 컷  ⑦ 부가 데이터 수집        → 11.2 핵심 지표는 남긴다
4순위 컷  ⑥ 인스펙터 UI            → 판정 로그는 남기고 화면만 축소
5순위 컷  ③ 손상 3층 중 1층(대사 미세 변형)  ← 유일하게 프롬프트 튜닝이 필요한 항목
── 여기까지가 한계. ①②④⑤와 손상 2·3층은 자르지 않는다 ──
```

<div class="callout">
  <div class="callout__title">손상 3층은 1층부터 자른다</div>
  <p>구현 난도가 크게 다릅니다 — <strong>충식 소실은 사실상 문자열 처리</strong>이고,
  <strong>노트 불일치는 기존 노트 시스템의 필드 하나</strong>이며, <strong>대사 미세 변형만 프롬프트 튜닝</strong>이 필요합니다.
  효과 대비 비용이 가장 나쁜 1층이 먼저 나갑니다.</p>
</div>

## 1회차 목표를 잘못 잡지 않기

기획서 12.1 마지막 항목이 중요합니다.

> 1회차 목표는 "살아남는 것"이 아니라 **"회피가 통하지 않는다는 것을 체감하고, 누가 왜 그러는지 알아내는 것"**

짧은 프로토타입에서는 "살아남았다"보다 **"알아냈다"**를 목표로 두는 편이 완성도가 높습니다.
난이도 튜닝과 엔딩 도달률 판단이 전부 여기서 갈립니다.

## 공개 투표 대응 (12.4) — 이것도 범위다

- 처음 보는 사람이 **30초 안에** 판단한다
- **로그인·설치·긴 튜토리얼 없이 즉시 진입**
- 첫 루프를 짧게 만들어 "되돌아갔다"를 빠르게 겪게 한다
- 소개 문구는 **표면 목표로 통일** ("매일 죽는 하루에서 살아남기"). 실제 구조는 플레이 중에 드러나게
- 회피가 부분적으로 통하는 **1~2루프를 초반에 배치**해 이탈을 막는다
- **"7시 12분. 눈을 뜬다."가 방문자가 보는 첫 화면**
- **커리어 시나리오도 같은 링크에서 진입 가능**하게 둔다

## 범위 밖 — 논의도 하지 않는다

- **계정 / 로그인 / 프로필** — 12.4 위반
- **모바일 네이티브 앱** — 기획서에 없다. 텍스트 웹으로 공개 투표에 나간다
- 게임 세계 바깥을 조회하는 도구 (외부 API·웹 검색·계산기) — 8.7 ③
- 파인튜닝 — "모델 선정 평가"까지만 말한다 (9.4)
- 판정 NPC 5인 확장 — 탐문 경로가 3 → 10으로 늘어 희소성이 깨진다 (4.2-1)
- 손상 4층 이상 (감정 어긋남·인물 기억 겹침 등) — 여유가 있을 때만
