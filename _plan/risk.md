## 읽는 법

각 리스크에 **트리거**(이런 신호가 보이면)와 **대응**(그때 이렇게 한다)이 붙어 있습니다.
트리거를 미리 정해두면 "좀 더 지켜보자"로 시간을 흘려보내지 않게 됩니다.

## 상위 리스크

### R2 · 3주 설계를 14일에 넣는다 — 심각도 높음 / 확률 높음

기획서 12장은 **3주** 기준입니다. 우리 데드라인은 **14일**. 일주일이 빕니다.

- **트리거** — D-7(9/09) 알파에서 1루프 완주 실패, 또는 방어선 5개 중 2개 이상 미착수
- **영향** — 방어선을 못 채우면 기획서 기준으로 **제출 자체가 성립하지 않음**
- **대응** — ① <a href="{{ '/plan/scope/' | relative_url }}">컷 순서</a>대로 ⑨→⑧→⑦→⑥→손상1층 순으로 기계적으로 제거 ② 하루 비트를 5개로 고정 ③ 그래도 안 되면 **엔딩 4종 중 2종만**(반복·인계) 구현하고 나머지는 텍스트로 축약
- **담당** — 류준

### R3 · 이은상(Flutter) 역할이 비었다 — 심각도 높음 / 확률 확정

기획서에 **모바일 앱이 없습니다.** 텍스트 웹으로 공개 투표에 나갑니다.
Flutter 담당 40건이 통째로 대상을 잃었습니다.

- **트리거** — 이미 발생. D-13(9/03) 안에 재배치하지 않으면 하루를 잃음
- **대응** — 웹 화면 5장을 **둘로 나눈다.**
  김충식 = 아침 화면 · 대화창 · 권고 배너 (게임 본류),
  이은상 = **루프 노트 · 인스펙터** + 전이 도메인 화면.
  인스펙터는 1차 사용자의 핵심 기능이고 노트는 대표 캡처 후보라, 비중이 가볍지 않다
- **대안** — Flutter 경험을 살려 **모바일 웹 최적화**를 전담 (공개 투표 유입의 상당수가 모바일)
- **담당** — 류준 · 이은상

### R4 · LLM 판정이 게임으로 성립하지 않는다 — 심각도 높음 / 확률 중간

기획서 2.5가 지목한 바로 그 벽입니다 — **"대화는 자연스러워지는데 게임이 되지 않는다."**

- **트리거** — D-8(9/08) 시점에 의심도가 발화 내용과 무관하게 움직임, 또는 같은 발화 반복 투입 시 판정이 흔들림
- **대응** — ① **계산은 코드, 판단은 LLM** 분리를 다시 확인 (8.5). 수치가 LLM에서 나오면 즉시 코드로 회수 ② 판정 일관성 실험(11.1 첫 행)을 앞당겨 실행 ③ 의심 판정 프롬프트를 좁힌다 — 자유 판단이 아니라 몇 개 범주 중 선택
- **담당** — 신채연

### R5 · 전이 시연 착수가 늦어진다 — 심각도 높음 / 확률 중간

방어선 ⑤인데 순위상 5번이라 **뒤로 밀리기 쉽습니다.**

> 기획서 10.3: 늦추면 짧은 작업이 안 끝나는 게 아니라 **아예 시작을 못 한다.**

- **트리거** — D-6(9/10)까지 어댑터 인터페이스 미착수
- **영향** — 3주차에 발견하면 못 고침. 14일이면 더 그렇다. 도메인 개념이 코어로 새어 들어갔는지를 **확인할 기회 자체가 사라진다**
- **대응** — 코어가 돌기 시작하면 **즉시** 첫 어댑터를 시도. 완성이 아니라 **막히는지만 확인**하는 30분짜리 작업으로 먼저 친다
- **담당** — 장민석 · 신채연

### R6 · 공개 투표에서 LLM 비용이 터진다 — 심각도 높음 / 확률 중간

로그인이 없으므로 **봇·크롤러·반복 접속에 그대로 노출**됩니다.

- **트리거** — 일일 사용량이 상한의 80% 도달, 또는 세션당 평균 루프 수가 비정상적으로 높음
- **대응** — ① 세션/IP당 루프 제한 ② 캐싱 ③ 컨텍스트 축소 ④ Agent 역할만 저가 모델로 하향 ⑤ 최후에는 대기열
- **담당** — 신채연 · 류준

### R7 · 텍스트 품질이 못 따라간다 — 심각도 중간 / 확률 높음

코드가 다 돌아도 **대사와 엔딩이 약하면 이 제품은 값이 떨어집니다.**
기획서가 "가장 공들여야 할 지점"으로 지목한 유일한 항목입니다.

- **트리거** — D-5(9/11)까지 엔딩 4종 텍스트 초안 미완
- **대응** — 코드 담당자가 쓰지 않는다. **텍스트 작업을 별도 카드로 분리**하고 시간을 따로 확보. 팀 3인 이상이 읽고 확인
- **담당** — 류준 (기획서 작성자가 문체를 가장 잘 안다)

### R8 · 발화 예산 숫자 미확정 — 심각도 중간 / 확률 확정

기획서 안에서 갈립니다 — **0장·4.3·5.1은 6회**, **12.1은 5회(하한 3)**.

- **트리거** — 이미 발생. 도메인 규칙은 테스트가 먼저 박히는 지점(9.3)이라 구현 착수를 막고 있음
- **대응** — PM이 D-13 안에 하나로 확정. 튜닝 여지를 남기려면 **설정값으로 빼고 기본값만 정한다**
- **담당** — 류준
