이 문서의 근거와 위치

기획서 v6의 12.2(화면 5장) · 4.9(연출 원칙) · 12.4(30초 진입) 를 UI로 번역한 것입니다. 프로젝트 예상안의 7번 섹션(와이어프레임)을 실제로 만질 수 있게 만든 버전이며, 참고용입니다. 확정 디자인은 07 디자인 시스템과 PM 결정을 따릅니다.

1 · 레이아웃 브레인스토밍 — 셋 중 무엇도 단독으로는 안 된다

A · 메신저형
카톡처럼 말풍선이 쌓인다

✓ 처음 보는 사람이 0초 만에 조작법을 안다 — 12.4의 30초 진입에 최적

✓ 발화 예산·전송 버튼이 자연스럽게 붙는다

✗ 미스터리 톤이 죽는다. 일상 앱처럼 보인다

✗ 서술(아침·죽음·정황)이 들어갈 자리가 없다

B · 소설형
비주얼 노벨처럼 문장이 흐른다

✓ 4.9 연출 원칙(정황과 단절)에 가장 맞는 톤

✓ 손상 1층(대사 미세 변형)이 텍스트 안에서 작동한다

✗ 예산·입력 같은 게임 UI가 붙을 자리가 어색하다

✗ "내가 지금 뭘 할 수 있지?"를 학습해야 한다

C · 터미널형
로그가 흐르는 콘솔

✓ 인스펙터와 시각 언어가 통일된다

✓ 1차 사용자(에이전트 개발팀)에게 어필

✗ 3차 사용자 — 게임을 안 하는 사람 — 에게 진입장벽

✗ 공개 투표에서 "개발자 장난감"으로 읽힐 위험

선택 — A+B 하이브리드, C는 인스펙터에만. 서술(아침·정황·단절)은 소설형 문단으로, 발화는 메신저형 입력으로, 시스템(침묵 권고·인스펙터)은 모노스페이스로. 한 화면 안에서 글꼴과 색이 층을 구분합니다 — 세리프는 세계, 산세리프는 대화, 모노는 기계.

2 · 목업이 쓰는 임시 토큰

게임의 소재에서 뽑았습니다 — 7시 12분의 새벽빛, 복사본의 복사본이 되어가는 세계, 종이 노트. 그래서 테크 블랙이 아니라 먹이 번진 어두운 세피아가 바탕이고, 이 개발 허브의 청록은 게임 프레임 안에서 일부러 쓰지 않습니다 — 허브(도구)와 게임(세계)이 색으로 구분됩니다. 컨셉 영상이 대조되면 07 디자인 시스템의 값으로 교체합니다.

잉크 바탕 #100e0b 바랜 활자 #d6cfc0 새벽빛 #b6c2ce — 아침·시간에만 연필 #8a8172 — 서술·노트 호박 #c9973f — 침묵 권고 기계 #6f9bbf — 인스펙터만

서체는 세 층이 세 목소리입니다 — 세리프는 세계(아침·정황·단절), 산세리프는 대화(사람의 말), 모노스페이스는 기계(판정·권고 근거). 움직임은 아침 문장 타자기 한 곳뿐이고 나머지는 전부 정적입니다.

4 · 직접 만져보기

기획서 8.8의 예시 시나리오가 그대로 스크립트로 들어 있습니다. 아침 → 대화(예산 소모) → 출처 빌린 거짓말 발각 → 침묵 권고 → 하루의 끝 → 2번째 아침까지 한 루프를 돌 수 있습니다. LLM 없이 전부 각본이며, 실제 게임에서는 NPC 응답과 판정이 전부 동적입니다.
