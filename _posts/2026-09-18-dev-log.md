### 임베딩 — 왜 빠졌었는지 기록하고, 한 자리에 되살리고, 3모델을 E7 기준으로 평가 (오전~오후)

출발은 사용자 질문 하나였다: "Core·NPC는 로컬도 외부도 다 평가했는데, 임베딩만 로컬이랑 비교를 안 했네?"

- **왜 빠졌었나 — 정본에 추가 기록(A.20).** 코드·DB 실사: `get_embedding()` 호출 0, `truth_claim_embeddings` 0행, `/health`에 표시 없음. 누락이 아니라 **09-06 채점 밸런스 조정에서 RAG top-3 절단 경로를 제거**(top-3만 심판에게 주던 게 "정답에 도달해도 21~42%"의 원인 — 8개 전부 주니 정답형 65.3→100.0)했고, 두 번째 용도 `search_notes`는 미구현. 즉 임베딩 모델을 비교하기 전에 쓰임새가 채점 캘리브레이션 축에서 탈락한 것. 기획서 확정본 v9.0(§11.5·§11.6)·Evaluation PART1(§5 Anchor)·팀원용 쉬운설명(§49)에 **원문 무수정으로 이력 블록 추가**(삭제 0줄), `apiscenario.md`의 틀린 미해결 과제("임베딩 무료 키 한도 제출 전 확인") 정정.
- **제출 뒤 변경 불가 → 제출 전에 구현·평가 가능한 건 전부.** 사용자 결정: 임베딩은 **① 직접 쓰기 규칙 대안 순위** 한 자리에만 되살린다(플레이어가 고르는 추천이라 틀려도 게이트 무해 — 09-06의 교훈 "임베딩으로 결정하면 틀렸을 때 조용히 깎인다"를 지킴). 채점·NPC 기억·단서 해금에는 안 닿게.
- **구현(A.21).** `alternative_rank.py` Strategy(`StemOverlapRank` 기본·`EmbeddingRank` 예외 시 어간 폴백 + warning 1줄), `ollama_embedding.py`(`/api/embed`, MRL `dimensions`, Qwen3 계열에만 query 지시문), Gemini `task_type` 두 갈래, 포트에 `embed_query`/`embed_documents`. 자매 프로젝트 **lifetutorial의 임베딩 방식을 참고 기준으로**(MRL 절단·L2 정규화·질의/문서 비대칭·"provider별 벡터는 한 컬럼에 섞지 않는다"). sonnet 검토 Critical 1(캐시 조회가 `try` 밖 → 짧은 응답 시 KeyError가 폴백 우회) + Major 1(지시문이 bge에도 붙음) 수정.
- **평가 — 3모델을 E7·E6과 같은 축으로.** 비교 러너 `run_rule_alternatives_eval.py`, 골든은 에이전트 초안 30문장 → **Scenario Director 검수 22문장**(뜻이 다른 8문장 제외, "포대를 들여다본다"는 "포대 자체가 뭔지 보는" 뜻으로 14·15 교체). 검수 골든 top-1: 어간 0.364 / **qwen3-embedding:4b@2560 0.909** / qwen@1536 0.818 / **bge-m3@1024 0.909** / **Gemini 0.955**(1024·1536·2560·3072 전부 동일 — 차원 무관). top-3는 임베딩 전 셀 1.000. **모델 간 순위 일치도**(벡터 코사인은 공간이 달라 무의미 — Kendall τ로): qwen2560↔1536 τ 0.90(절단 무해), Gemini↔qwen τ 0.31~0.36, **Gemini↔bge-m3 τ 0.59~0.63** — bge-m3가 Gemini와 가장 닮은 로컬 모델. 반복 n=3 적중률·오답 집합 3회 완전 동일(결정론). 공통 오답 1건 "은상이 본 대로 얘기하게"(6셀 전부 "들은 것을 그대로 전한다"로 — 모델 공통 한계, top-3엔 포함).
- **서버 실경로·VRAM 동주 — 여기서 결정이 갈렸다.** 별도 포트/테스트 DB에서 HTTP `/rule/preview` 임베딩 순위 확인("스피커실"→"방송실에 간다" 어간 3위→임베딩 1위), ollama 차단 시 200+어간 폴백. VRAM(RTX 5060 Ti 16GB): gemma4 8.1 + kanana 5.3 + **qwen3-embedding:4b 4.4GB(실상주) = 17.7GB → 임베딩 호출이 Core·NPC 둘 다 축출**(2/2, 재로드 4~6.5s). **bge-m3 0.66GB → 14,187 MiB 셋 다 온칩·축출 0**(2/2). 서버→ollama 본문 프록시 캡처로 지시문 미부착·1024 반환 실증.
- **결정(사용자).** 차원은 둘 다 2560(Gemini는 무손실, qwen은 무절단 — Settings 기본). **최종 구성: 프로덕션 = Core·NPC Anthropic + 임베딩 Gemini@2560 / 로컬 개발·롤백 = gemma4 + kanana + bge-m3@1024**(`.env` `EMBEDDING_PROVIDER=ollama` 한 줄, `Settings.embedding_model` 기본 `bge-m3`). qwen@2560은 로컬 단독 최적 기록으로만. metrics.yml +30줄, A.21 §1~§8.
- **A.19 후속 과제 닫음 — planner beats 상한 결정적 절단.** Anthropic 구조화 출력이 `maxItems`·`maximum`을 못 받아 재생성·폴백이 나던 결함. `cut_to_max_length` 헬퍼(필드 `MaxLen` reflection)로 `NpcPlan.beats`(꽉 찬 계획만 번호 위치 재부여 — sonnet 검토 Major: `beat: 7` 혼입)·`AdvisorOptionsOutput.options`·`AdvisorReplyOutput.evidence`. 프롬프트 "정확히 6개" 한 줄. 테스트 5건, **960 passed**.
- **러너 3종 `--provider anthropic`** — `runner_common.make_provider_llm`(프로덕션 팩토리 경유), ollama 기본 경로 실주행 3건 동일. `run_paw_eval`은 self-play 판을 읽는 러너라 라벨만. **Anthropic 키 런북(self-play→paw_eval→채점 캘리브레이션→누설)은 최종 시나리오까지 끝난 뒤 마지막에 한 번**(사용자 결정, 오늘 밤 실행 취소).

### 신의 질문 개선 (테스터9 F16·F19·F20, 테스터10 F5)
- "알 수 없다"면 질문 횟수를 환급한다(한 밤 3회 상한, 같은 질문 재입력은 차감, 안내 질문은 무차감). 화면은 판정 배지와 첫 문장 → "내일 해 볼 일" 조언 블록 → 나머지는 접기 순서로 바꿨다.
- 게임 목적·사용법 질문은 키워드 표로 분류해 모델 호출 없이 고정 안내로 답한다. 입력창 위에 두 사용법(가설 판정 / 기록 찾기)을 적었다.
- 시나리오에 공개 사다리 8칸을 두고 회차·최고 점수(25점 단위)로 한 칸씩 연다. 조언자 입력에는 열린 칸만 들어가고, "알 수 없다" 답에는 사다리 원문이 나가지 않는다. 실제 모델 스모크에서 unknown이 10/10 → 7/10으로 줄었다.
- 리뷰에서 Critical 두 건(동시 요청으로 환급·호출 상한 우회, 연결 풀 고갈 시 모델 호출 뒤 롤백돼 무료 재호출)이 나와 A등급으로 올려 잠금·감사 기록 분리로 고쳤다.

### 비용 동시성 차단 (5b)
- 낮 장면·밤 제출·회차 시작의 잠금을 전부 NOWAIT로 바꿨다. 앞 요청이 처리 중이면 기다리지 않고 409(`request_in_flight`)를 돌려준다. 채점 중 답안 수정도 같은 잠금으로 묶어, 채점한 문장과 저장된 문장이 어긋나던 경로를 막았다.
- 제출 응답을 이벤트에 저장해, 채점 뒤 연결이 끊겨도 재제출이 같은 응답을 받는다(모델 호출 0).
- 모델 호출 감사 기록은 전용 작은 풀에 쓰고 실패해도 롤백하지 않는다 — 모델을 불렀으면 차감이 남는다.

### NPC 답변 품질 (테스터9 F14)
- 민석 수첩 내용이 비어 있어 모델이 둘러대던 문제를 시나리오 데이터로 채우고, 기억·질문에 없는 숫자와 자기 행동 부정을 거부하는 검사를 넣었다. 실제 모델로 세 사례 전부 개선을 확인했다.

### 설정 메타포 정리
- 손목띠·침상 명판·민석 수첩의 표식은 인물 눈에만 숫자·이름이고 사람 기준으로는 글자가 아니다. 사람(관리자) 쪽 글자는 아무도 읽지 못한다. 인물별 손목띠 번호를 고정값으로 정의해 모델이 지어내지 못하게 했다.
